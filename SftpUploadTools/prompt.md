需要帮我写一个powershell脚本，做文件迁移，最后将生成的脚本保存到工作目录下，脚本文件名称为:`file_incr_achr.ps1`

## 问题背景

现在有一个场景，服务器上的某个目录中，每天都会产生新的文件保存在该目录下或者该目录的子目录下，截至到目前，该目录总共已经有几十个G的大小了。
现在我需要迁移该目录下的所有文件，要求该目录下的文件层级结构都不变，迁移到其他服务器。
虽然最简单的做法是直接copy该目录或者将该目录直接压缩，但是导致最终传输的文件过大，受到网速的影响，迁移过程太慢了，进而导致了迁移时间窗口期过长；
且迁移期间无法识别和保证是否有新文件再次产生到某个子目录中，导致迁移遗漏，所以全量迁移的方法不可靠。
我需要一个增量迁移的方案，主要是解决以下几个问题：

- 解决网络不稳定，导致中途迁移失败的问题; 由于是增量迁移，所以迁移窗口期不会太长。
- 解决迁移时，部分新产生的文件漏掉的问题; 如果新文件产生了，那可以在做一次增迁移。

所以需要实现一个脚本，能够把某段日期区间内的文件导出并归档到一个指定的目录中，我就可以将归档目录中的文件做增量迁移了。

## 脚本实现要求

实现一个powershell脚本，环境windows server 2019。

### 脚本功能描述

脚本至少接收如下几个参数：

1. 左闭右开的日期区间参数，格式比如为：`2026-06-01 00:00:00 2026-06-02 00:00:00`
 表明日期至大于等于2026-06-01 00:00:00，但是小于2026-06-02 00:00:00
2. 文件根目录，需要在该目录下进行文件及子文件扫描的目录
3. 归档根目录，将符合扫描结果的文件及子文件归档至该目录下
 归档时，不能直接归档至该根目录，需要在该目录下创建一个子文件夹，将文件及子文件归档至该子文件夹下。该子文件夹命名为日期区间参数(注意日期中的特殊符号替换)。

在文件根目录下，过滤出所有符合在日期区间内创建的文件及其子文件(根据文件创建时间判定)，并将这些文件，按照其现有的目录结构，归档至新的指定目录下。

### 使用示例讲解

假设存在如下文件根目录(该目录下可能时时刻刻都会有文件或者子文件创建)：

`D:\Programs\SFTP\ROOT\`

在文件根目录下存在如下的现有文件结构：

```
创建日期 文件路径结构(基于文件根目录)
2026-06-01 12:01:56 file001.txt
2026-06-01 10:01:56 file002.txt
2026-06-02 10:01:56 file003.txt
2026-05-02 10:01:56 file004.txt
2026-06-01 15:23:23 obtain/file001.xlsx
2026-06-01 15:23:23 obtain/file002.xlsx
2026-06-02 16:23:23 obtain/20260602/file003.xlsx
2026-05-02 16:23:23 obtain/20260602/file004.xlsx
2026-06-02 00:00:00 obtain/20260601/file005.xlsx
...
```

归档根目录为：
`D:\Programs\SFTP\Achv\`

现在希望将`2026-06-01 00:00:00 2026-06-02 00:00:00`时间区间内容创建的文件归档到`D:\Programs\SFTP\Achv\`目录中，则文件根目录中各个文件是否符合的情况如下：

```
创建日期 文件路径结构(基于文件根目录) 是否符合
2026-06-01 12:01:56 file001.txt 符合
2026-06-01 10:01:56 file002.txt 符合
2026-06-02 10:01:56 file003.txt 不符合
2026-05-02 10:01:56 file004.txt 不符合
2026-06-01 15:23:23 obtain\file001.xlsx 符合
2026-06-01 15:23:23 obtain\file002.xlsx 符合
2026-06-02 16:23:23 obtain\20260602\file003.xlsx 不符合
2026-05-02 16:23:23 obtain\20260602\file004.xlsx 不符合
2026-06-02 00:00:00 obtain\20260601\file005.xlsx 不符合，因为要求日期区间为左闭右开，所以不能等于2026-06-02 00:00:00
```

所以最终符合过滤条件的文件列表如下：

```
创建日期 文件路径结构(基于文件根目录)
2026-06-01 12:01:56 file001.txt
2026-06-01 10:01:56 file002.txt
2026-06-01 15:23:23 obtain\file001.xlsx
2026-06-01 15:23:23 obtain\file002.xlsx
```

然后将上述符合条件的文件归档至归档根目录`D:\Programs\SFTP\Achv\`.归档步骤为：

1. 在归档根目录下创建一个子文件夹，如：`D:\Programs\SFTP\Achv\20260601.000000-20260602.000000`.子文件夹的名称格式根据日期区间参水来格式化，格式为：`yyyyMMdd.HHmmss`,如此是为了清楚归档的内容是什么时间段的文件。
2. 将文件根目录`D:\Programs\SFTP\ROOT\`中符合条件的文件归档至`D:\Programs\SFTP\Achv\20260601.000000-20260602.000000`目录下。
所以最终归档的文件结构效果如下：

```
归档文件的路径结构
D:\Programs\SFTP\Achv\20260601.000000-20260602.000000\file001.txt
D:\Programs\SFTP\Achv\20260601.000000-20260602.000000\file002.txt
D:\Programs\SFTP\Achv\20260601.000000-20260602.000000\obtain\file001.xlsx
D:\Programs\SFTP\Achv\20260601.000000-20260602.000000\obtain\file002.xlsx
```
